TOEIC MASTER — iPhone PWA 콘텐츠 개선판
빌드: 2026-11-28

포함 콘텐츠
- 최종 어휘 2,412개(기존 앱 단어와 제공 PDF 통합, 표제어 중복 제거)
- 85페이지 토익 단어장 PDF: 2,110개 표제어 행 추출(2,109개 번호 인덱스와 한 행의 추가 병렬 항목 포함)
- 6개 시험일자별 100단어 PDF: 597개 항목 추출(9월 6일 자료의 apostrophe 포함 구문도 별도 보완)
- 모든 단어의 뜻 필드가 비어 있지 않음. PDF에 예문이 없는 85페이지 단어장은 뜻 중심으로 수록
- Part 5 문제은행 500문항: 기초 107, 중급 276, 고급 117
- 12개 유형: 품사, 동사, 준동사, 접속사, 전치사, 관계사, 대명사, 형용사·부사, 비교, 조동사·가정법, 어휘, 어휘·숙어
- 10문제 단위 테스트, 중간 저장·이어 풀기, 신규 테스트 시작, 오답 복습, 완료 결과 및 기록

데이터 출처와 제한
- PDF 단어의 뜻·예문은 제공 PDF에서 추출·정리했습니다. 일부 85페이지 표는 두 열의 병렬 항목과 줄바꿈이 있어 행 구조를 보완했습니다.
- 100단어 PDF 597개 항목 중 555개는 예문을 연결했습니다. 텍스트 줄바꿈으로 예문 문장 전체를 온전히 확인하지 못한 30개 항목은 추측하지 않고 예문을 비워 두었습니다. 85페이지 단어장 PDF에는 예문이 없어 뜻 중심으로 반영했습니다.
- PDF 수록 빈도는 실제 TOEIC 전체 시험의 출제 빈도 통계가 아닙니다.
- Part 5 문제는 학습용 자체 제작 연습문제이며 실제 기출문제가 아닙니다.
- 원자료의 저작권 및 이용 조건은 각 권리자에게 있습니다. 개인 학습 목적으로 사용하세요.

설치
1. ZIP 압축 해제 후 모든 파일을 HTTPS 웹 호스팅에 업로드합니다.
2. iPhone Safari에서 HTTPS 주소를 엽니다.
3. 공유 → 홈 화면에 추가를 선택합니다.
4. 기존 설치본이 있다면 새 파일을 호스팅 경로에 덮어쓰고 앱을 다시 실행합니다.

기록 저장
- 학습 데이터는 해당 기기의 브라우저 저장 공간에 저장됩니다.
- 앱을 지우거나 Safari 웹사이트 데이터를 삭제하기 전에 설정 화면에서 백업을 내보내세요.
- 서비스 워커 캐시 버전이 갱신되었습니다.
