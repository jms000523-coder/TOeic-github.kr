중복 제거 방식
- 대소문자, 연속 공백, 하이픈·기타 구두점 차이를 정규화한 뒤 같은 표제어를 하나로 통합
- 같은 단어가 여러 PDF에 있으면 하나만 남기고, 확인 가능한 뜻·예문·해석은 보강
- 기존 앱의 단어와도 대조하여 최종 중복 제거

출처 및 이용상 주의
- 이 버전의 단어 데이터는 사용자가 업로드한 PDF 7종에서 추출·정리했습니다.
- PDF에 수록된 횟수는 실제 TOEIC 시험의 출제 횟수가 아닙니다. 본 앱은 이를 최근 4개년 전수 출제 빈도 통계로 표시하지 않습니다.
- 업로드된 Hackers 자료 등 원자료의 저작권·이용 조건은 각 권리자에게 있습니다. 개인 학습 목적으로만 사용하고 앱이나 추출 데이터를 재배포하지 마세요.
- 앱의 Part 5 문항은 학습용으로 작성된 연습문제입니다.

설치 방법
1. 압축을 풀고 폴더 안의 모든 파일을 HTTPS 웹 호스팅에 업로드합니다.
2. iPhone Safari에서 배포된 HTTPS 주소를 엽니다.
3. 공유 버튼 → 홈 화면에 추가를 선택합니다.
4. 앱 최초 실행 후 설정에서 목표 점수와 시험일을 입력합니다.

주의
- 오프라인 실행은 최초 HTTPS 접속 및 서비스 워커 캐시 이후 지원됩니다.
- 학습 기록은 기기 브라우저 저장 공간에 저장됩니다. 설정 화면에서 JSON 백업을 내보낼 수 있습니다.
- 새 버전은 서비스 워커 캐시 버전을 갱신했습니다. 업데이트가 바로 반영되지 않으면 Safari에서 새로고침하거나 홈 화면 앱을 다시 실행하세요.
